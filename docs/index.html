Выбрать поле ввода на ТВ

Русские буквы доходят до ТВ, если на нём включены «Специальные возможности» (приложение включает их само через ADB). Без них работает только латиница.

Код ТВ с экрана приложения
MQTT-брокер (тот же сервер, что у ТВ; страница подключается по wss)

Код хранится только в этом браузере. Кто знает код, тот может управлять ТВ, поэтому никому его не показывайте. Если в приложении создали новый код, введите его здесь заново. Страницу можно открыть сразу с кодом: …/#abcd-efgh-ijkl.
