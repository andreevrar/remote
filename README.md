# ТВ-пульт: приложение для ТВ + страница на GitHub Pages

Как это работает:

```
телефон: страница на GitHub Pages ──wss──▶ публичный MQTT-брокер ◀──wss── приложение на ТВ
                                                                              │
                                                  ADB на самого себя (127.0.0.1:5555)
                                                  + служба спец. возможностей (текст, запасной путь)
```

Bluetooth не нужен, достаточно интернета на телефоне и на ТВ. Пульт работает и вне дома.

## Что внутри

- `app/` — Android-приложение (Kotlin). Фоновая служба + экран с кодом.
- `docs/index.html` — страница пульта. Вкладки: **Пульт**, **Клавиатура**, **Связь**.
- `.github/workflows/build.yml` — сборка APK на GitHub (ставить Android Studio не нужно).

## Установка

1. Создайте репозиторий на GitHub и загрузите в него всё содержимое этой папки (кнопка *Add file → Upload files*, либо `git push`).
2. **Страница:** Settings → Pages → *Deploy from a branch* → ветка `main`, папка `/docs`. Через минуту страница откроется по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`.
3. **APK:** вкладка Actions → *Build APK* (запускается сам после загрузки, либо кнопкой *Run workflow*). Готовый файл `tv-remote.apk` лежит в артефактах запуска, а также в Releases → «Последняя сборка».
4. Скопируйте `tv-remote.apk` на флешку и установите на ТВ (нужно разрешение на установку из неизвестных источников).
5. Запустите приложение. На экране ТВ появится запрос **«Разрешить отладку по ADB?»**. Выберите **«Всегда разрешать»**. После этого приложение само включит себе службу специальных возможностей.
6. На телефоне откройте страницу пульта, на вкладке «Связь» введите **код с экрана ТВ** и нажмите «Подключиться». Индикатор сверху станет зелёным.

Если приложения нет в списке программ на ТВ, запустите его из файлового менеджера или командой `adb shell monkey -p app.tvremote 1`. Дальше приложение стартует само при включении ТВ.

## Если что-то не работает

| Что видно | Что делать |
|---|---|
| На экране ТВ «ADB: нет» | В настройках для разработчиков включите отладку по ADB (по сети). Приложение подключается к `127.0.0.1:5555`. Затем нажмите «Перезапустить службу» и подтвердите запрос. |
| Кнопки не нажимаются, но ТВ «на связи» | Нужен ADB или «Спец. возможности». Без ADB работают только Назад, Домой, стрелки (двигают фокус) и OK (нажимает выбранное). |
| Русский текст не вводится | Нужны «Спец. возможности: включены» (кнопка «Включить спец. возможности через ADB» в приложении). Через ADB проходит только латиница. |
| «ТВ не в сети» | Приложение не запущено или у ТВ нет интернета. Некоторые ТВ в режиме ожидания отключают сеть, тогда пульт не разбудит ТВ. |
| Обрыв связи с брокером | Публичный брокер иногда недоступен. Брокер можно сменить и в приложении (`Config.DEFAULT_BROKER`), и на вкладке «Связь», например на `wss://broker.emqx.io:8084/mqtt`. Адрес должен быть одинаковым на обеих сторонах. |

## Безопасность

Связь идёт через публичный брокер, а «паролем» служит длинный случайный код (12 символов). Любой, кто его узнает, сможет нажимать кнопки на вашем ТВ, но выполнить произвольную команду не сможет: приложение принимает только фиксированный список кнопок и ввод текста. Если код попал не туда, нажмите на ТВ «Сгенерировать новый код».

## Протокол (для доработок)

Топик команд: `tvr/<код>/cmd`, сообщения JSON:

- `{"t":"key","k":"UP"}` — кнопка (список в `Keys` в `Config.kt`: UP, DOWN, LEFT, RIGHT, OK, ENTER, BACK, HOME, MENU, VOL_UP, VOL_DOWN, MUTE, CH_UP, CH_DOWN, POWER, SLEEP, WAKEUP, PLAY_PAUSE, REWIND, FF, NEXT, PREV, DEL, SPACE, SEARCH, SETTINGS, INFO, 0–9)
- `{"t":"text","v":"привет","m":"append"}` — дописать текст в поле ввода (`"m":"replace"` — заменить)
- `{"t":"ping"}` — попросить ТВ прислать статус

Топик статуса: `tvr/<код>/status` (retained), например `{"online":true,"adb":true,"acc":true}`.
